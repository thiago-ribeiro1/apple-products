# Apple Scrollytelling

Aplicação web desenvolvida com **Next.js**, **Tailwind CSS**, **GSAP ScrollTrigger** e técnicas de **Scrollytelling**.

O objetivo do projeto é explorar animações interativas baseadas no movimento de scroll, criando uma experiência visual inspirada em páginas modernas de produtos Apple.

<img width="1906" height="902" alt="Image" src="https://github.com/user-attachments/assets/a4287f61-eb65-4099-9754-c5f586649f95" />

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP
- ScrollTrigger

## Sobre o projeto

Este projeto foi criado como um experimento front-end para testar:

- Animações com GSAP
- Controle de timeline com ScrollTrigger
- Transições baseadas no scroll da página

## Como rodar o projeto

Clone o repositório:

```bash
git clone https://github.com/thiago-ribeiro1/apple-products.git
cd apple-products
npm install
npm run dev
```
